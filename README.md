# 🎭 Kịch Bản Tiểu Phẩm: RƯỢU VÀO… KỶ LUẬT RA
### Hội Thi Tuyên Truyền & Phổ Biến Giáo Dục Pháp Luật (React + Vite App)

> Ứng dụng web React.js hiện đại, tương tác mượt mà, phân vai rõ nét. Đã triển khai chính thức trên **Vercel** tại đường dẫn: [https://kichbanhoithiphapluat.vercel.app](https://kichbanhoithiphapluat.vercel.app).

---

## 🌟 Tính Năng Trên Ứng Dụng React

1. **Framework React.js & Vite**:
   - Quản lý trạng thái (State) tức thời, phản hồi nhanh chóng.
   - Bảng màu phân biệt rõ từng vai diễn trong số 9 nhân vật.
   - Thiết kế dạng thẻ, phân 5 cảnh kịch bản rõ ràng, kèm hiệu ứng âm thanh (SFX).

2. **Lọc vai diễn & Tìm kiếm thời gian thực**:
   - Bấm vào từng nhân vật để highlight toàn bộ lời thoại của vai đó, làm mờ các vai khác để diễn viên dễ tập trung.
   - Tìm kiếm nhanh thoại, hành động với từ khóa highlight vàng.

3. **Giao diện Tối / Sáng (Dark & Light Mode)**:
   - Nút bật tắt chế độ Sáng / Tối lưu vào LocalStorage.

4. **🔊 Đọc thoại bằng giọng nói (Text-to-Speech)**:
   - Tích hợp giọng đọc Tiếng Việt phát âm từng câu thoại.

## 🛠️ Cài Đặt & Chạy Cục Bộ (Local)

```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển
npm run dev

# Đóng gói sản phẩm
npm run build
```
